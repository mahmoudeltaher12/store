# RASI

متجر ملابس عربي تجريبي بواجهة RTL متجاوبة. لا يحتاج Node.js أو خطوة بناء.

## التشغيل

افتح `index.html` في المتصفح. صور المنتجات والخطوط محمّلة من الإنترنت، لذلك يلزم اتصال بالشبكة لعرضها.

## المزايا التجريبية

- استعراض المنتجات والبحث والتصفية والترتيب حسب السعر.
- تفاصيل المنتج واختيار المقاس والمفضلة وسلة محفوظة محليًا.
- إتمام طلب تجريبي يظهر في لوحة الإدارة.
- شات تجريبي، والرسائل تظهر في لوحة الإدارة.
- دخول الإدارة التجريبي: `admin@rasi.com` وكلمة المرور `rasi123`.

تسجيل الدخول والدفع والشات ليست خدمات حقيقية؛ البيانات محفوظة في المتصفح الحالي فقط، ولا يوجد خادم خلفي أو معالجة مدفوعات.
